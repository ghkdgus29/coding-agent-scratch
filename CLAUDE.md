# Project: coding-agent-scratch

## Purpose
Scratch workspace for testing and developing coding agent workflows, experiments, and prototypes.

## Architecture
- Empty project directory for ad-hoc coding tasks
- No fixed stack — adapt to whatever experiment needs

## Key Commands
- `claude -p "task"` — Print mode for one-shot tasks
- `claude` — Interactive REPL for multi-turn work
- `claude remote-control` — Start remote control server for web/mobile access

## Code Standards
- Follow existing patterns in whatever language/framework used
- Write tests for non-trivial logic
- Keep experiments isolated and cleanable

## Notes
- This is a scratchpad — no long-term commitments
- Feel free to create/delete files freely
- Use `--allowedTools` to restrict capabilities per task
